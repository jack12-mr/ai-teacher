# 管理后台部署指南

## 概述

管理后台已分离为国内版和国际版,通过环境变量 `NEXT_PUBLIC_DEPLOYMENT_REGION` 控制数据库连接。

## 国内版部署

**域名:** https://morncoach.mornscience.top

**环境变量:**
```
NEXT_PUBLIC_DEPLOYMENT_REGION=CN
NEXT_PUBLIC_CLOUDBASE_ENV_ID=<YOUR_CLOUDBASE_ENV_ID>
CLOUDBASE_SECRET_ID=<YOUR_CLOUDBASE_SECRET_ID>
CLOUDBASE_SECRET_KEY=<YOUR_CLOUDBASE_SECRET_KEY>
ADMIN_SESSION_SECRET=<YOUR_ADMIN_SESSION_SECRET>
```

**管理员账号:**
- 用户名: <YOUR_ADMIN_USERNAME>
- 密码: <YOUR_ADMIN_PASSWORD>

## 国际版部署

**域名:** https://mornhub.biz

**环境变量:**
```
NEXT_PUBLIC_DEPLOYMENT_REGION=INTL
NEXT_PUBLIC_SUPABASE_URL=<YOUR_SUPABASE_URL>
NEXT_PUBLIC_SUPABASE_ANON_KEY=<YOUR_SUPABASE_ANON_KEY>
SUPABASE_SERVICE_ROLE_KEY=<YOUR_SUPABASE_SERVICE_ROLE_KEY>
ADMIN_SESSION_SECRET=<YOUR_ADMIN_SESSION_SECRET>
```

**管理员账号:**
- 用户名: <YOUR_ADMIN_USERNAME>
- 密码: <YOUR_ADMIN_PASSWORD>

## 部署步骤

1. 设置环境变量
2. 运行数据库初始化脚本
3. 部署应用
4. 验证管理员登录功能
